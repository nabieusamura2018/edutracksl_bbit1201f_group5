# EduTrack SL

## Smart Student Attendance and Academic Performance Management System

---

## Overview

EduTrack SL is a digital school management system designed to improve attendance tracking, academic performance monitoring, and communication between schools and parents.

The platform provides a centralized solution that allows teachers, parents, and school administrators to access important educational information in real time, reducing reliance on manual processes and improving decision-making within educational institutions.

This project was developed as a Digital Public Good under the PROG102 – Principles of Software Engineering module at Limkokwing University of Creative Technology, Sierra Leone.

---

## Problem Statement

Many educational institutions still rely on manual methods to record attendance, track academic performance, and communicate with parents. These traditional approaches often result in inaccurate records, delayed communication, inefficient administration, and limited access to student information.

EduTrack SL addresses these challenges by providing a centralized digital platform that improves efficiency, transparency, and accountability within the education system.

- View student records
- Generate reports

### Parent Module

- Monitor attendance records
- View academic performance
- Track student progress
- Receive school notifications

### Administrator Module

- Manage students

- Manage classes
- Generate reports
- Monitor system activities

## System Modules

### User Management

Handles authentication, user registration, login, and profile management.

Supports attendance recording, monitoring, and reporting.

### Academic Performance Management

Supports grade recording, performance tracking, and result analysis.
